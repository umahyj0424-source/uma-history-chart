# UMA RACE ATLAS — GitHub Pages Edition

독립 실행형 HTML / CSS / JavaScript 경주마 타임라인. 별도의 서버나 npm 설치가 필요하지 않습니다.

## GitHub Pages에 게시하기

1. ZIP을 압축 해제해 `index.html`, `styles.css`, `app.js`, `seed.js`, `assets/`, `portraits/`, `race-thumbnails/`을 확인합니다.
2. GitHub에서 새 저장소를 만든 뒤 이 파일들을 **저장소 최상위 폴더**에 업로드합니다. `index.html`이 최상위에 있어야 합니다.
3. 저장소의 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`, 브랜치 `main`, 폴더 `/(root)`를 선택합니다.
4. GitHub Pages가 제공하는 URL로 접속합니다. 공개 저장소를 사용하면 데이터·코드가 공개되니 공개 여부를 확인하세요.

GitHub Pages 버전은 서버 없이 작동합니다. 처음 실행하면 포함된 135마리 경주마, 2,146개 경기, 2,926개 출전 기록, 271개 의상이 나타납니다.

## 데이터 수정과 이미지

- `데이터 관리`에서 경주마, 경기, 출전, 의상을 추가·수정·삭제할 수 있습니다.
- 수정 사항은 **이 브라우저의 localStorage**에만 저장됩니다. 다른 PC, 다른 브라우저, 시크릿 모드에는 자동 동기화되지 않습니다.
- **JSON 백업**을 정기적으로 수행하고, 다른 브라우저에서는 **JSON 가져오기**로 병합하세요.
- 134마리의 일반 의상 프로필 사진을 `portraits/`에 포함했습니다. 이 폴더와 `seed.js`를 함께 배포하면 캐릭터 선택 목록·타임라인·상세 화면에서 표시됩니다. `ファレノプシス`의 사진은 아직 없고, 8장의 여분 이미지도 이 폴더에 따로 보존했습니다 (`portraits/manifest.json`).
- G1 레이스의 기본 썸네일을 `race-thumbnails/`에 포함하고, 경주 상세 패널에서 볼 수 있도록 경기 기록에 연결했습니다. `race-thumbnails/manifest.json`에는 각각의 출처 URL 및 적용한 경기 건수가 기록되어 있습니다.
- 캐릭터와 경기 이미지 URL은 기록 편집 화면의 `이미지 URL` 항목에 입력할 수 있습니다. 기존 이미지가 없으면 빈 슬롯이 표시됩니다.
- GitHub에 이미지를 추가하려면 `assets/images/`에 파일을 넣고, 이미지 URL에 `./assets/images/파일명.png`와 같은 **상대경로**를 입력하면 됩니다. GitHub Pages에서 사용하려면 이미지 파일도 저장소에 함께 업로드해야 합니다.
- 작은 이미지 파일은 편집창에서 데이터 URL로 읽을 수 있지만, 이미지가 많으면 브라우저 저장 용량 한도에 걸릴 수 있습니다. 많은 이미지는 위 상대경로 방식을 권장합니다.

## 배포본 구분

| 종류 | 기록 저장 | 이미지 업로드 | 적합한 용도 |
| --- | --- | --- | --- |
| ChatGPT Sites 원본 웹사이트 | 로그인 계정의 D1 데이터베이스 | R2 서버 | 지속적인 기록 관리 |
| GitHub Pages ZIP | 브라우저 localStorage | 저장소 파일 경로·이미지 URL | 정적 공개 열람 및 개인별 편집 |

두 버전의 변경 사항이 자동 동기화되지는 않습니다. JSON으로 옮겨야 합니다.

## 포함 파일

- `index.html`: 정적 사이트 진입점
- `styles.css`: 디자인 및 반응형 레이아웃
- `app.js`: 타임라인·편집·백업 기능
- `full-export.js`: 전체 연대기 SVG/PNG 이미지 생성기
- `seed.js`: 기본 데이터 (JSON을 JS 파일로 내장해 `file://` 열기에서도 동작)
- `portraits/`: 사용자가 제공한 원본 캐릭터 이미지 142장(134장 매칭·8장 추가 보관) 및 매칭 명세
- `race-thumbnails/`: 나무위키 G1 표의 원본 WebP 썸네일 및 출처·명칭 대조 기록
- `assets/images/`: 이후 이미지 파일 추가 위치

이 데이터는 검수·보완 중인 작업본입니다. 역사적 기록의 정확성, 소스의 라이선스, 사진의 사용 권한은 공개 전에 검토하세요.

## 전체 이미지 내보내기

타임라인 아래의 **전체 SVG · 원본 화질**은 1976~2021년 모든 경주마와 경기 기록을 SVG 한 파일로 만듭니다. 벡터 기반이라 도트·선·글자는 크게 확대해도 깨지지 않으며, 브라우저가 읽을 수 있는 원본 이미지의 바이너리를 SVG 안에 그대로 포함합니다. 외부 서버가 이미지 다운로드를 차단하거나 브라우저 저장 용량 한도에 걸리면 해당 사진은 빈 슬롯으로 남습니다.

게임 캐릭터 일러스트 및 G1 레이스 썸네일의 저작권은 별도로 확인해야 합니다. 특히 GitHub Pages로 외부 공개하기 전 재배포 가능 여부를 검토하세요. 이 ZIP에 포함된 출처 표시는 사용 허락을 대신하지 않습니다.

**전체 PNG · 고화질**은 같은 그림을 PNG 한 장으로 출력하되, 브라우저 안정성을 위해 약 5,500만 픽셀 이내에서 크기를 자동 조절합니다. 인쇄·무한 확대·원본 사진 보존이 중요하면 SVG를 사용하세요. 이미지가 많을수록 생성 시간이 길어질 수 있습니다.
